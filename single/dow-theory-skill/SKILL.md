# 道氏理论（专业解读版）THE DOW THEORY — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 日内与短线交易信号（道氏理论时间尺度为主要趋势层级）
- 个股买卖点位推荐与个股相对强度系统（指数不指导个股）
- 精确逃顶/抄底点位预测（只有信号分级与统计预期）
- 经济预测宏大叙事与 1903-1929 历史时评（作为 Boundary 与案例背景保留）
- 预测次日或短期涨跌（"明天涨还是跌"类问题超出晴雨表分辨率，一律不受理）

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 平均价格指数反映一切（不可抗力除外）——不接受此前提者不应使用本体系
2. 两种指数必须相互确认；未被确认的新高新低几乎是假象
3. 市场同时存在主要运动、次级运动与日间波动，判读前先锁定运动层级
4. 主要运动绝不可被人为操纵；日间波动很可能受操纵、次级运动所受影响有限
5. 道氏理论是实践科学而非不败体系；方向可判、持续时间不可预测

## 边界与判停

- 信号矛盾或不可读，输出空仓观望直至信号清晰
- 单指数未确认，按"等待确认/假象"处理，不入场也不反向
- 统计分布（33%~66%、40%~60% 等）仅作预期校准，不得当作买卖触发器
- 3%/5% 等阈值为讨论单位而非交易阈值，高位须按点位百分比放宽
