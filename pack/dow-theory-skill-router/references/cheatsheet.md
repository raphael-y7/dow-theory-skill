# 决策规则速查 — 道氏理论（专业解读版）THE DOW THEORY

| 能力 | 一句话规则 |
|---|---|
| 主要趋势判定（高低点阶梯＋3%净逆转＋牛熊反转判据） | 以两指数高低点阶梯＋3%净逆转切分运动并经相互确认，输出牛市/熊市/待确认的方向结论； 结论按"信号持续到被抵销或增强"维护，牛转熊与熊转牛各有二值判据。 |
| 双指数相互确认过滤器（未确认信号＝假象） | 任何单指数信号先判确认状态——另一指数跟进（不必同日）则采信、暂未跟进则等待、 始终未确认则按假象忽略；仅一方信号按无信号处理，两指数都失守才可断言趋势改变； 附带指数数据质量门槛（剔除失真期与公司行为机械位移、禁用失真替代指数）。 |
| 次级运动识别与幅度评估（33%~66%＋速度不对称＋完成序列） | 判定当前反向运动是次级运动还是趋势反转：3 周至数月、通常回撤前一主要运动的 33%~66% （区间极宽）、速度快于主要运动；牛市回调完成须四条件量价序列齐备； 回撤超 85% 或双指数破位则疑似反转，按趋势程序确认。 |
| 线态窄幅盘整判读（吸筹/派发推断与突破方向） | 两指数均在约 5% 幅度内波动两三周以上即为线态盘整——形成期不预判性质， 等双指数同时突破定吸筹/派发方向；单指数的"线"或单指数突破不可下结论。 |
| 量价关系健康度评估（超买超卖与沉闷/活跃语义） | 指数永远第一位、成交量第二位——量能信号不得推翻指数判读；以升缓跌活/跌缓升活判定超买超卖， 量缩回调＝超卖预示反弹、量增价滞＝过度活跃警报；"绝不在沉闷市场做空"须按趋势语境条件化。 |
| 牛熊三阶段定位器（按驱动锚定位并校准风险态度） | 以"信心恢复→已知收入改善→靠希望上涨"（牛市）与"希望破灭→经济萧条抛售→被迫变现贱卖优质股"（熊市） 三锚定位当前阶段并输出对应风险态度（第三阶段＝靠希望上涨，最危险应保守）；辅以价格÷股利回报倍数的 价值测试（1924 年约 6 倍→1927 年 11 倍→1928 年 17 倍→1929 年 22 倍的逐级抬升＝价格趋向超出价值的警标）。 |
| 熊市底部特征核查清单（图 1 九次熊市统计画像） | 底部确认按七项勾检（谷底 60~90 天振幅 3% 内、量能提前数月萎缩、利空钝化、沉闷、 窄幅盘整向上突破、双重底不可作指标、10%/20% 时机）——齐备升"底部概率高"，任一缺省降级观察； 确认判据＝不再创新低＋双指数越过上次重大反弹高点。 |
| 牛市顶部信号分级与清仓决策（1929 年 9—10 月标本） | 顶部不做点位预测、只做信号分级响应：前兆监测→顶后首跌按次级处理→反弹高点递降＋量价背离→ 双指数破位确认→分级清仓；1929 标本给出"低于峰值 10% 执行清仓＝满分操作"的可检验标准。 |
| 个股操作的大盘趋势前置检查（防呆闸门） | 任何个股操作前先过大闸门——"必须像理解公司资产负债表一样理解市场的趋势"： 主要趋势向上（或底部确认）才允许做多；熊市中绩优股同样被贱卖甚至更脆弱，不得以个股强势反推大盘。 |
| 交易纪律与资金管理原则包（止损/仓位/加码方向/收益预期） | 止损是第一课、固执己见是损失首因；上涨后加仓、禁下跌摊平、禁顶部金字塔； 仓位减到可以睡着为止；心存疑惑什么也不做、大损后彻底离场； 年收益预期 12%~20%、每 10 次交易至少 7 次获利且一年很少超过四五次。 |
| 预测自检训练法（盖图预测—对照汉密尔顿评论—归因差异） | 盖住历史图表先写预测与理由，再对照汉密尔顿专栏原文，归因差异并记录例外； 配套失误归因复盘：区分"信号错误"与"解读错误"（1926 标本五步程序）。 |
| 次级反应统计基准与数据基建（35 年分布预期＋记录模板＋除数法） | 回调/反弹预期只用统计分布校准、禁止当触发器：次级运动平均 52.2 天/回升 57.6%、 73% 于 55 个交易日内结束、恐慌后反弹约 40%~60%、牛 25 个月熊 17 个月； 数据基建＝收盘价＋成交量输入模板、运动记录表、除数法。 |
| 伪信号与归因排查（前提门槛＋反模式清单） | 遇"双顶双底/主力砸盘/重磅消息/黑天鹅"先过排查清单：逐项对照书中反模式与前提门槛， 输出"无效＋替代程序"判定（双顶底改用破位＋确认；操纵归因三层检验；头条只当温度计）。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
