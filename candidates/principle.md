- id: p01
  title: 人为操纵的三层次公理
  type: principle
  source_chapter: 上篇第2章（定义）、第3章
  source_quote: |
    "平均价格指数的日间波动很有可能受人为操控，次级运动也会受到相对有限的影响，但是市场主要的运动趋势是绝对不会被人为影响的。"
  summary: |
    把"操纵"的作用范围限定为三层：日间波动可被操纵、次级运动所受影响有限、主要运动绝对不会被操纵。
    第3章以1929年9月1日纽交所总市值逾890亿美元、操纵10%所需资金规模为理据；"即使美国财政部与美联储联合起来，
    也没有任何一种力量可以操纵40支活跃股票"（1923-04-27）。业余者把趋势变化归因于神秘"庄家力量"是仅次于急躁的亏损原因。
  tags: [principle, axiom, manipulation]

- id: p02
  title: 平均价格指数反映一切（含使用门槛）
  type: principle
  source_chapter: 上篇第2章（定义）、第4章
  source_quote: |
    "那些否定这一原理的人，最好的选择就是不要尝试使用道氏理论。"
  summary: |
    指数日收盘价反映所有涉足金融事务者的希望、失望与知识的综合判断；未来事件（不可抗力如火灾地震除外）
    总被预期性反映。雷亚要求初学者"必须绝对相信"，并把接受三大假设作为运用道氏理论的先决条件——
    否则"不是会被彻底地误导，就是会产生困惑"（第2章）。
  tags: [principle, axiom, emh]

- id: p03
  title: 交易基于可预见的最佳消息，而非众所周知消息
  type: principle
  source_chapter: 上篇第4章（《华尔街日报》1913-01-20、1906-06-29）
  source_quote: |
    "市场并不是在众所周知的消息基础上进行交易的，而是基于可预测到的最佳消息进行交易。"
  summary: |
    消息见报时相关行情已经走完；重大新闻刊登时其对基本趋势的影响力早已被消化。
    由报纸头条引发的情绪反应，除非市场当时已处超买或超卖状态，否则站不住脚（第3章）。
    操作含义：读报跟风注定滞后，指数判读优先于新闻判读。
  tags: [principle, news, timing]

- id: p04
  title: 道氏理论并非真理（实践科学定位）
  type: principle
  source_chapter: 上篇第5章
  source_quote: |
    "道氏理论不是可以击败市场的不败体系。投资者若想成功地将道氏理论运用到投资中需要严肃认真地钻研，并且毫无偏见地总结收集来的证据，绝不能让主观愿望超越理性思考。"
  summary: |
    道氏理论与外科、飞行同属实践科学（相对精确科学如数学只有一种答案），并非一贯正确；
    运用得当需长期坚持不懈地钻研；失败多因急躁、误读信号或主观愿望压倒理性。
    这一定位本身构成理论的使用边界。
  tags: [principle, axiom, epistemology]

- id: p06
  title: 三种运动并存与重要性排序
  type: rule
  source_chapter: 上篇第6章
  source_quote: |
    "平均价格指数包括三种运动，这三种运动或许会存在于同一时间。"
  summary: |
    主要运动（牛市/熊市，持续1年至数年）最重要、次级运动（牛市重要回调/熊市重要反弹，3周至数月）最具欺骗性、
    日间波动最不重要。分析前必须先锁定自己解读的是哪一层运动；次级运动如刹车、日间波动如油门（汽车类比）。
  tags: [rule, structure, three-movements]

- id: p07
  title: 判断方向是关键，持续时间不可预测
  type: principle
  source_chapter: 上篇第7章；下篇第20章（1929-10-21等多处重申）
  source_quote: |
    "正确判断主要运动的方向，是成功操作的关键因素。目前，人们还没有找到可以预测主要运动持续时间长短的方法。"
  summary: |

    "能预报哪天下雪、不能预报降雪3.5英寸"（第10章次级运动同理）。
  tags: [principle, scope, forecast-limit]

- id: p09
  title: 两种指数必须相互确认（第一纪律）
  type: principle
  source_chapter: 上篇第12章；第2章（定义）
  source_quote: |
    "只有在一种平均价格指数被另一种确认后，才可以得出可靠的结论。"
  summary: |
    全书"一天都不能忘记"的部分：单指数结论"经过长时间检验后无可避免地会造成灾难"；
    "承认一种平均价格指数，却没有得到另一种平均价格指数的确认，是最容易犯的错误之一"（《股市晴雨表》）。
    雷亚以"钢铁厂重建高炉→铁路运输先行→工资→零售"的经济循环推理补足理据。
    A股适配："专业解析"建议以上证指数与中小板指数叠加观察背离（译者类比，未经雷亚方法论检验）。
  tags: [principle, confirmation, core]

- id: p10
  title: 消极保险规则——单指数指示不如不判断
  type: rule
  source_chapter: 上篇第12章（《华尔街日报》1928-07-27）
  source_quote: |
    "两种平均价格指数若只判断其中的一个指示，还不如不判断。另一种平均价格指数必须与其相互确认。"
  summary: |
    把未确认信号按"无信号"处理：这是比积极寻找信号更保险的读数规则，

  tags: [rule, confirmation, filter]

- id: p11
  title: 未确认的新高新低几乎是假象
  type: rule
  source_chapter: 上篇第12章（《华尔街日报》1913-06-04、1921-05-10）；第13章
  source_quote: |
    "一种平均价格指数创造出一个新低点或者一个新高点，却没被另一种平均价格指数确认，这几乎是假象。"
  summary: |
    历史规律：每一次主要运动之前两指数总是同时创新高或新低（1921-05-10）。
    未确认的运动偶尔意义重大，但常常只表明次要变化（第13章）；
    单指数新低未获确认时，"可能发生的趋势变化只是次级运动趋势，并非主要运动趋势的反转"（第8章）。
  tags: [rule, confirmation, false-signal]

- id: p12
  title: 两指数方向一致、力度可异（适用边界）
  type: rule
  source_chapter: 上篇第12章（《股市晴雨表》引文）
  source_quote: |
    "两种平均价格指数在力度上可能会有所不同，但是在方向上却不会有本质上的差别，特别是在主要运动中。"
  summary: |
    该规律适用于主要运动与次级运动及反弹；对日间波动不适用，应用到个股"也许会出现严重的误导"——
    界定确认规则的适用范围，防止把指数规律错用到日级或个股层面。
  tags: [rule, confirmation, boundary]

- id: p13
  title: 确认不必同日；确认后单指数独行无妨
  type: rule
  source_chapter: 上篇第12章（《股市晴雨表》）、第13章（1921-12-30）；下篇第20章（1924-08-11）
  source_quote: |
    "主要运动的低点或高点，绝对没有必要由两种平均价格指数在同一天创造出顶部或底部。"
  summary: |
    两指数确认不必同日甚至同周（"不必在同一天，或者甚至不在同一周，只要二者互相确认"）；
    同日同周发生"只是一种巧合"（1924-08-11）；一经相互确认即可假定转变成立，
    此后单指数再创新高/新低而无确认，"也无妨"。
  tags: [rule, confirmation, timing]

- id: p14
  title: 相互确认主要出现在主要运动初期
  type: rule

  title: 两指数都失守才能断言趋势改变
  type: rule
  source_chapter: 下篇第20章（《巴伦周刊》1928-03-05）
  source_quote: |
    "直到两个平均价格指数都没能创出新高或新低，我们才能充满信心地做出趋势改变的预测。"
  summary: |

    预测主要趋势改变需两个指数同时失败——过滤单板块背离的过度解读。

- id: p16
  title: 指数失真期剔除与替代品禁用
  type: rule
  source_chapter: 上篇第12章（章末及脚注）；下篇第20章（1923-08-29）
  source_quote: |
    "学者们在研究平均价格指数时会发现，把这段时期排除在外是极其明智的。"
  summary: |
    一战期间铁路被联邦接管、收益固定，铁路指数"波动与债券一样"失去确认能力，研究该时期应剔除；
    1923年起所得税/免税债券抛压亦扭曲指数（1923-08-29专栏）。
    公用事业指数不可替代铁路指数——领先公司间存在连锁关系，指数受一两只股票直接影响（脚注）。
  tags: [rule, data-quality, exclusion]

- id: p18
  title: 趋势判定的操作定义（高点/低点阶梯＋3%净逆转）
  type: calculation
  source_chapter: 上篇第13章；第2章（定义）
  source_quote: |
    "价格的恢复或下跌被定义为：一个或多个交易日导致任意一种平均价格指数超过3%的净逆转。"
  summary: |
    把"趋势"从描述变为程序：以两指数高点/低点阶梯的抬升/递降定义牛市与熊市，
    以3%净逆转作为标记一次回升/下跌完成的最小讨论单位；所有趋势信号须双指数确认方有权威。
  inputs: 两指数日收盘价序列
  formula: 反弹高点逐级抬升且回落不低于前期低点＝牛市信号；反弹不超前高且低点递降＝熊市信号；以"超过3%的净逆转"标记一次回升/下跌的完成，且回升/下跌须两指数确认
  units: 3%为相对指数点位的百分比
  output: 当前主要趋势状态（牛市／熊市／待确认）及次级运动评估
  missing_conditions: 3%是"为了便于讨论"的讨论单位而非买卖阈值；基于1920s点位与波动率，当代校准方法书中未给
  tags: [calculation, trend, threshold]

- id: p19
  title: 牛转熊确认规则
  type: rule
  source_chapter: 上篇第13章（《华尔街日报》1928-06-25）
  source_quote: |
    "当两种平均价格指数都下跌到前期次级运动的低点以下时，才具有重要意义。"
  summary: |
    牛市中剧烈次级运动后若在合理时间内不能创新高、且进一步下跌跌破前期次级低点并获双指数确认，
    可"比较肯定地假设主要趋势已经从牛市变为熊市"；第13章注明检验35年图表后该规则"包含一些例外"。
  tags: [rule, trend-change, confirmation]

- id: p20
  title: 熊转牛确认规则
  type: rule
  source_chapter: 上篇第13章；下篇第20章（1921-09-21）
  source_quote: |
    "下一阶段的下跌不能使两种中任意一种平均价格指数创造新低，而接下来的反弹能使两种平均价格指数都在上次重大反弹的高点之上，或许就可以推断主要趋势已经从熊市向牛市转变了。"
  summary: |
    熊转牛判据＝不再创新低＋双指数同步反弹越过上次重大反弹高点；
    1921-09-21补充："两个平均价格指数的新高点甚至略高于它们上次记录的高点，那么我们处在一个牛市中或许是一条合理的规则。"
  tags: [rule, trend-change, bottom]

- id: p22
  title: 次级运动定义与33%~66%回调口径
  type: rule
  source_chapter: 上篇第10章、第2章（定义）、第13章
  source_quote: |
    "次级运动的价格一般会回调到前一个主要运动终止后价格变化的33%～66%。"
  summary: |
    定义：牛市重大下跌/熊市重大上涨，持续3周至数月；重要次级运动普遍追回前期主要运动的1/3~2/3甚至更多。
    配套要求："每位交易者在观察次级运动时，都务必要考虑交易量"（第10章）。
    精确限度不可求——"想尝试给次级运动定出精确限度的人们，注定会失败"，如同预报降雪3.5英寸。
  tags: [rule, secondary-reaction, retracement]

- id: p24
  title: 速度不对称原则
  type: rule
  source_chapter: 上篇第8、10章（《华尔街日报》1910-03-19、1910-08-30）
  source_quote: |
    "在持续时间超过 1 年或者更久的牛市运动中，与偶尔回调相比，上涨过程看起来比较缓慢。同样地，在熊市中，反弹确实要迅速得多。"
  summary: |
    次级运动速度总比其主要运动快："持续若干周的主要运动常常只需短短几天就可以完成回调"；
    熊市反弹"时间短且速度快"。速度特征是区分次级运动与主要趋势反转的判据之一，
    也是"牛市不以剧烈反弹开始"（p39）的机理基础。
  tags: [rule, secondary-reaction, speed]
